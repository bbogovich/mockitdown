# Demos

The demo site (F-14) is published with this documentation, at [`/demos/`](../../demos/). Every
picture on it is generated at build time from a fenced block of SwiftUI-style code; most blocks show
their source under the figure. The same pages are the project's end-to-end test.

## Language

- [Language tour](../../demos/tour/) — elements, modifiers, layout, data, navigation, images, appearance
- [Custom components](../../demos/components/) — `struct` views and `import "…"` libraries
- [Annotations and overlays](../../demos/annotations/) — numbered callouts, pointers, drag-select
- [Beyond the framework kits](../../demos/widgets/) — spreadsheets, boards, editors, chat, schedules
- [Charts](../../demos/charts/) — fifteen chart types
