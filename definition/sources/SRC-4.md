---
id: SRC-4
title: "Request: more platforms, non-standard components, overlays and annotations, charts"
recorded: 2026-11-24
---

> This works very well so far. Add Android standard UI framework, GTK, QT, KDE-Plasma with their default theme
> as options. Recommend other common UI frameworks. Our primary target is MacOS and iOS apps, but also heavy
> emphasis on web development. Add UI elements for commonly seen non-standard components including spreadsheets,
> sticky notes, create others using your best judgement. We will also need to support overlays - for example,
> being able to represent a drag-select with a border and tint. A pointer and labelled annotation need to be
> supported to illustrate workflows and call out specific elements (usually numbered in a colored background
> circle, attached to an element in the view, which are then referenced in surrounding paragraph text). Add
> common charts and graph types. Extra packs: Windows 3.1.1 and a star trek LCARS style interface - this is an
> easter egg for developers reading the documentation as a reward for reading the whole thing.
