## Site structure (R-PACK-012, F-14)

Both sites enable `navigation.tabs` and list the same five top-level entries in the same order:
Demo · Definition · Specification · Implementation · Reference. Each site's own sections are nav
sections; the other site's are absolute URLs. The **Reference** section
(`examples/site/docs/reference/`) is generated by `tools/gen_reference.py` from the pack definitions,
including its block of `examples/site/mkdocs.yml` between the `>>> reference nav` markers. After any
pack change: `.venv/bin/python tools/gen_reference.py` (the test suite fails when stale). Retro packs
are ordered chronologically by `RETRO` in that script and in the Demo nav; kits by `KITS`.

## Core backlog reported by the pack agents (worked around in the packs)

- Overlay elements (`r_toast`, `r_dialog`, `r_fab`) drop `.callout()` decorations (`_wrap_overlays`
  decorates only when there is output). A toast inside `.overlay(alignment: .topTrailing)` disappears
  (the badge translate rule applies to panels too).
- `MenuItem` with children and `open: true` inside `Menu` does not open a submenu (Avalonia, NeXTSTEP).
- `_tr` does not pass `data-el` on table rows; no per-column `filter:` header icon.
- Element `attrs` can only rename; no value mapping (`outline: true` → variant) or inversion
  (`isEnabled: false` → disabled). `_SAFE_TOKEN` rejects `/` in colours (`dark/zinc`).
- Dotted element names (`Badge.Ribbon`) do not parse; packs join them (`BadgeRibbon`).
- `.callout` has no `offset:`; `.position(x:y:)` centres the view.
- An `HStack` child with `.frame(maxWidth: .infinity)` and no intrinsic width collapses unless the
  stack has a `Spacer`. A `ZStack` child with `maxWidth: .infinity` does not fill.
- `.sheet { Dialog(…) }` leaves an empty sheet (the dialog moves to its own layer).
- Code role: no `added:`/`removed:` line states for diffs; packs cannot ship their own SVG icons
  (git/Octicon glyphs are stand-ins).
- Several toasts cannot stack in one corner; access-key underscores (`_File`) show literally.
- Unknown labelled arguments are dropped without a warning.

Fixed in this session: blank `Text("")` keeps a line; arrays/strings `contains`, `hasPrefix`,
`hasSuffix`; `Table` sees rows/columns inside `Group` wrappers; `Badge(count: 1)` no longer a dot;
`Progress(kind: "circle"|"dashboard")` is circular; inline code no longer gets the code block's box;
a menu stays right-aligned when a callout layer follows it.
