D1: By default (`css: inline`) the extension prepends one `<style>` per page holding the CSS of the packs that page used.
D2: With `css: none` the site links a stylesheet generated by `mockitdown css` itself.
O1: rejected: copy CSS files into the site (the prototype plugin's approach) — needs a plugin (ADR-3).
O2: rejected: inline styles per element — huge output and no pack CSS cascade.
O3: rejected: inline the full CSS of every pack on every page — loads packs a page does not use.
C1: Zero configuration for most sites; pages with mockups are self-contained.
C2: Sites with many mockup pages can opt into one cacheable stylesheet.
