Scope: R-PACK-015 (all).

Both variants (Python renderer and TypeScript port) stay byte-identical: change shared/ CSS once, port renderer changes, regenerate shared/conformance (gen_conformance.py) and shared/reference (gen_reference.py). Diagnosis from the define step: fit frames are squeezed to the host width (page.css .mkd-cell max-width:100%, HStack min-width:0) so variant rows overlap; .mkd-layer is position:absolute so presentations collapse at fit; base pack.css gives circle/ellipse/capsule border-radius:9999px and an explicit frame overrides aspect-ratio; scatter/bubble/heatmap/candlestick ignore values:.
