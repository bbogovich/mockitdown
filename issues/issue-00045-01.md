Analysis. Cause: the parser reads an element name as a single identifier, so a dotted name such as Badge.Ribbon (antd, SRC-12#s13 HANDOFF backlog) does not parse; packs work around it with joined aliases (BadgeRibbon). Spec pages: R-LANG-007 (C8, TC-2) and R-EVAL-003 (C9, C10, TC-2), F-2.CR-1 (C7, AC4). Fix: parse a dotted element name in both variants and resolve it to the pack's joined name; conformance cases for both variants.
