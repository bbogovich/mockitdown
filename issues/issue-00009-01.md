Analysis. Cause: (1) shared/packs/base/pack.css line 141 gives circle, ellipse and capsule border-radius:9999px; aspect-ratio:1 on the circle is overridden by an explicit .frame(width,height), so Circle and Ellipse render as capsules in every pack (SRC-9#ellipse). (2) The chart renderer draws scatter, bubble and candlestick only from points: and heatmaps only from matrix:, so values: (what the gallery sample passes) yields an empty <svg>. Spec pages: REND.1 (R-REND-014 new), REND.2 (R-REND-012.C6, C7). Proposed fix: circle = min(w,h) square centred in the frame; ellipse border-radius:50%; capsule radius = half the shorter side; derive marks from values per R-REND-012.C6; warn code chart when no data.
