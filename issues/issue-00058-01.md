Done in b94f64a (docs 94b2d5c): specification 0.12.9, implementation 0.3.27, IT-35 to IT-37.

Fixed while writing the test cases:
- R-DEV-006 TC-2: frames inherited letter spacing (and could inherit other text properties) from `.md-typeset`, and Zensical's `.md-typeset kbd` gave Kbd keys a box shadow. `shared/css/page.css` now sets those properties on `.mkd-frame`, adds `kbd` and `box-shadow` to the reset, and has `.mkd-figure .mkd-frame kbd { box-shadow: none }`.
- R-LANG-006 TC-1 (C2): a ternary's `?` at the start of the next line was a syntax error. Both parsers now accept it. The new conformance case `lang-expressions` covers this.

As built: R-DEV-002.C2, R-DEV-003.C3/C4, R-DEV-005.C4/C5, R-EVAL-002.C4 (new: placeholders in the preview instance), R-EVAL-008.C2 (`%g`), C5, C7. Correction: R-DEV-007.C1 cited R-DEV-004 where it meant R-DEV-005.

Open suspects (same tier, so `vio-docs repin` refuses them; nothing needs to change): ADR-2 → R-EVAL-011 and ADR-7 → R-DEV-003 (test cases and as-built wording only); R-DEV-008 and R-DEV-010 require R-DEV-001 (TC-1 added, no clause changed).

Seen but not changed:
- `@Environment(\.x) var y` with no default is still a required argument when the struct is called explicitly, so pasted views with environment properties report "missing argument". R-EVAL-011.C1 as written allows this.
- `V.x` that reads a static property of struct V from inside V recurses ("nests too deeply").
- Interpolating a call value (`\(GridItem(.flexible()))`) prints Python's dataclass repr. No clause specifies this text.
- `t.1.1` lexes `1.1` as a number. This is noted in the R-LANG-006 prose.
