Mockup element

<mockitdown-mockup> renders the code in its <script type="text/mockitdown"> child into a shadow root, with the stylesheet of the packs it uses. Attributes are the Markdown fence's (pack, device, appearance, chrome, title, id, url, width, height, caption, elements, source, window) plus import-base and asset-base. The script may contain <, > and & as they are; the one thing it cannot contain is </script — set such code with the code property.
