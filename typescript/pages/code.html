Code view element

<mockitdown-code> is a light code editor for mockitdown: coloured text, line numbers, diagnostics in the gutter (the message of the caret's line below), bracket matching and auto-indent. Tab and Shift+Tab indent and outdent the selected lines; press Esc then Tab to leave it.
